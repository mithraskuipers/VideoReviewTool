VideoReviewTool

Skim, sort and clean videos in seconds - or turn each one into a quick screenshot-grid preview.

Point this at a single video file or a whole folder of them to get started. On the next screen you'll choose whether to review them one by one, or generate a screenshot compilation image for each.

Drop a video file or folder here

Browsers can't read a real disk path from a drag-and-drop action, so use one of the buttons below to choose reliably - or paste the path directly.

Supported formats: .mp4, .avi, .mov, .mkv, .webm, .flv, .wmv, .m4v, .mpg, .mpeg, .ts
